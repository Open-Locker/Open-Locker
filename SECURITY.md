# Security Policy

## Supported versions

Security reports are accepted for the current `main` branch and the latest
component tags: `backend-v*`, `client-v*`, and `mobile-v*`.

## Reporting a vulnerability

Report it privately through
[GitHub Security Advisories](https://github.com/Open-Locker/Open-Locker/security/advisories/new).
If you cannot use GitHub, email [moin@merona.de](mailto:moin@merona.de).

Do not open a public issue for a suspected vulnerability.

## What to expect

We aim to acknowledge a report within a few business days and to follow up
after we have looked at it. There is no 24/7 response.
