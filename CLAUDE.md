# Open-Locker agent guidance

Use [AGENTS.md](AGENTS.md) as the concise repository map. Detailed, conditional
guidance is managed through `agents.toml` and `.agents/skills/` by dotagents.
When working inside a component, load the matching skill named in AGENTS.md;
do not copy its contents into this file.

The repository is a Laravel backend, Expo mobile app, Node/Raspberry Pi
MQTT-to-Modbus client, static Astro website, hardware designs, and shared docs.
Check manifests and source before trusting older documentation.
